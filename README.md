# E-nk.OS
OS for a e ink display e book reader. Actively workshopping this. This repo inherits alot of logic from the Openbook and LibreOS due to this project serving as a learning project rather than a full fledged solo OS.

## What it Does

E-nk.OS is an operating system for e-ink display e-book readers built on the ESP32-S3 microcontroller. The current implementation includes e-ink display management with full and partial refresh capabilities, SD card file system scanning and navigation at the root directory level, text rendering using the Babel typesetter library, button input handling for up, down, and select actions, file listing display with selection highlighting in the user interface, and category filtering framework with dropdown menu support.

## What's going to be Done

Implement file navigation through subdirectories with back functionality, add file opening and reading from SD card storage, implement file type detection and appropriate rendering handlers for supported formats, complete the category filtering system for organizing files, add file content display and pagination for readable text output, implement file search and sorting functionality in the file browser, add settings and configuration management for user preferences, implement status indicators and error handling for user feedback, and establish power management and standby modes for battery efficiency.
